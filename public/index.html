☁️ Vercel Cloud Database Setup (100% Libre)

Sa Vercel Serverless, ang file system ay ephemeral / stateless (naglalaho pagkatapos ng cold-start). Para 100% permanenteng ma-save ang lahat ng in-activate at binura mong users:

🚀 1-Click Setup sa Vercel Dashboard (Libre):

  1. Pumunta sa iyong Vercel Project sa vercel.com/dashboard.
  2. I-click ang Storage tab sa itaas.
  3. Piliin ang Upstash (o KV) at i-click ang Create Database (Free Tier).
  4. I-click ang Connect to Project at piliin ang iyong HWID project repo.
  5. I-click ang Redeploy sa Vercel. Tapos na! Awtomatikong magko-connect ang database.
⚡ Built-in Browser Sync:
Habang hindi pa naka-connect ang Upstash, naka-save din ang iyong database sa iyong browser! Pwede mong i-click ang ⚡ Sync Server button anumang oras para i-sync ang iyong mga HWIDs sa Vercel container.

🔐 Admin Authentication

Ilagay ang iyong Admin Secret / PIN para ma-manage ang mga HWIDs. (Default: admin123).
